= FDO Secret Service Integration with KeePassXC

This feature allows KeePassXC to act as a Secret Service (FreeDesktop.org) provider over DBus, allowing applications to store and retrieve secrets securely via standard APIs. For more information, see link:https://github.com/keepassxreboot/keepassxc/tree/develop/src/fdosecrets[src/fdosecrets]


=== Prerequisites

* Linux desktop with DBus and Secret Service support
* KeePassXC version 2.7.x or newer
* A `kdbx` database with an unlocked group for exposing secrets

=== Enabling the Integration

1. Open KeePassXC → **Tools → Settings → Secret Service Integration** → check **Enable KeePassXC FDO Secret Service**.
+
.FDO SSI Tools Setting
image::FDO_Tool_SSI.png[]

2. Go to **Database → Database Settings → Secret Service Integration**, enable **Expose entries under this group**, and select the desired group.
+
.FDO SSI Database Setting
image::FDO_Database_SSI.png[]
3. Unlock the database prior to querying secrets.
